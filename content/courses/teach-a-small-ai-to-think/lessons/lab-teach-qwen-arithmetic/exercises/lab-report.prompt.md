# Write your five-line lab report

After running the module 5 notebook to the end, write a report with exactly these five lines:

1. **Setup:** model, number of steps, group size, learning rate, beta, max completion length, LoRA rank.
2. **Before / after:** accuracy and format rate on the 200 held-out test questions.
3. **Curves:** one sentence each on total reward, completion length and `frac_reward_zero_std`, based on the rolling averages.
4. **Examples:** one test question the model got right after training but not before (quote the key part of both answers), and one it still gets wrong.
5. **Next change:** one knob you would change in your next run, and the curve or example that made you choose it.

**Done looks like:** five lines with your own real numbers (no invented ones), short enough to fit on an index card.
